PageRank

Por que uma página recebe mais importância que outra?

PageRank é um algoritmo que estima a importância de uma página pelos links que apontam para ela.

Cada link funciona como uma indicação. Uma indicação vinda de uma página importante tem mais peso. O algoritmo repete essa troca até chegar a uma ordem estável.

PageRank mede importância na rede de links. A relevância para uma busca e a qualidade do conteúdo exigem outros critérios. Esta é uma visualização didática, não a busca atual do Google.
