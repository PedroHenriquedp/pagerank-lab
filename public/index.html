PageRank

Por que uma página recebe mais importância que outra?

PageRank é um algoritmo que estima a importância de uma página pelos links que apontam para ela.

Cada link funciona como uma indicação. Uma indicação vinda de uma página importante tem mais peso. O algoritmo repete essa troca até chegar a uma ordem estável.

O que os links revelaram?

1

A e B apontam para C

C recebe importância das duas páginas e fica em primeiro.

2

C aponta para A

A recebe uma indicação da página mais importante e fica em segundo.

3

C passa a apontar para D

C divide sua importância entre A e D. Com essa indicação, D sobe.

O algoritmo repete essa troca de importância até a ordem se estabilizar. PageRank mede a posição na rede de links; a relevância para uma busca e a qualidade do conteúdo exigem outros critérios. Este exemplo não reproduz a busca atual do Google.
